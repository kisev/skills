# Introduction and Goals

The system packages deduplicated Agent Skill sources for portable Pages and OpenCode use.
Its goals are discoverable capabilities, bounded orchestration, safe optional
installation, observable lifecycle state, reproducible distribution, and
evidence-backed compatibility. Stakeholders are skill users, OpenCode users,
maintainers, host agents, and evaluators.

The public target has inventory `27/27/6/3/1`; requirements are in
`requirements/` and evidence is in `traceability.json`.
