# Solution Strategy

Keep capability behavior in deduplicated English definitions, materialize
self-contained skills in an isolated build, and publish digest-bound archives
from validated release tags. Keep package integration thin: catalog and registry define
the public surface, the core plugin routes and exposes tools, and lifecycle code
validates ownership and digests. Use preview/confirm/apply for mutation, stable
structured reports for orchestration, and hostless deterministic evals for
behavioral coverage.
