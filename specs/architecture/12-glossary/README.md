# Glossary

- **Capability**: a public skill, command, agent, plugin, or package tool.
- **Core plugin**: the always-available OpenCode infrastructure plugin.
- **Receipt**: a one-use routing authorization bound to task evidence.
- **Execution card**: confirmed structured work authorization for implementation.
- **Exact-owned**: ownership proven by the managed manifest and content digest.
- **Materialization**: build-only generation of autonomous skills or host assets
  from canonical source content.
- **Distribution archive**: one public digest-bound autonomous skill artifact.
- **Stable Pages channel**: the moving well-known URL for the latest release.
- **Partial**: useful bounded output with explicitly reported missing evidence.
