# Architecture Constraints

The architecture preserves self-contained published archives, deduplicated Git
sources, the native V2 boundary in
[REQ-I-420](../../requirements/interfaces/README.md#req-i-420---native-opencode-v2-interface), explicit ownership,
no-network hostless evals, and content-addressed archival. Normative constraints are defined once in
`requirements/constraints/README.md`; this view records their architectural
consequences only.
