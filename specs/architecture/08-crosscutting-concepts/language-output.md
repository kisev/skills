# Language and Output

Canonical specification prose is English-only. Stable IDs, paths, JSON fields,
commands, and technical names remain unchanged. Human and machine outputs use
structured status, evidence, and error fields; secrets are redacted. Capability
documents reference this section rather than repeating the language policy.
GitLab review publication prose is written from the authenticated user's factual
role. It does not narrate that user in the third person or invent actions and
promises. Direct address uses natural informal second-person singular in the
selected language without forcing a pronoun into neutral technical prose.
