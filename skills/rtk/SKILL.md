# Выборочное использование RTK

RTK - внешний CLI, не устанавливаемый этим skill. Проверь доступность из каталога
skill через `python3 -I -S -B scripts/rtk.py check`. При отсутствии runner вернёт
JSON `escalate`; не устанавливай инструмент автоматически.

Используй RTK для первого обзора больших, повторяющихся и преимущественно
информационных выводов: полных тестов, сборок, линтеров, сводок Git и логов.
Сжатый вывод может быть отфильтрован, дедуплицирован, усечён, суммирован или
переупорядочен. Отсутствие данных в нём не является доказательством отсутствия.

Всегда запускай исходную команду напрямую, когда нужен полный, точный,
упорядоченный или машиночитаемый вывод, включая code review, диагностику,
проверку безопасности, deployment, запись, удаление, migration и доказательство
отсутствия объекта или ошибки.

## Рабочий процесс

1. Для шумной операции используй RTK как широкий первый проход.
2. Выдели конкретный тест, файл, ошибку, ресурс или временной диапазон.
3. Для решения или точного доказательства выполни узкую исходную команду.
4. Не включай hook автоматической подмены команд без отдельного запроса.

Примеры:

```shell
rtk pytest tests/
pytest tests/test_contract.py -vv

rtk git status
git diff -- path/to/file
```

Перед использованием незнакомой обёртки прочитай `rtk --help` или
`rtk <command> --help`. Детальные границы по категориям инструментов находятся в
`references/per-tool.md`.
