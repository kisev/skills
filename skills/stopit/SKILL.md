# Передача контекста

## Граница

- Создавай новый файл во временной директории ОС, не в репозитории.
- Не меняй репозиторий, `.gitignore`, состояние Git или внешние системы.
- Не копируй логи, секреты, персональные данные и большой контекст. Используй
  обезличенный итог и точные ссылки на существующие артефакты, пути или SHA.

## Порядок работы

1. Учти переданный фокус как назначение следующей сессии.
2. Собери только проверяемые факты из диалога, репозитория и существующих
   артефактов. Отдели решения от предположений и незакрытых вопросов.
3. Подготовь новый черновик. Используй по необходимости разделы `Решения`,
   `Текущее состояние`, `Блокеры`, `Следующие шаги`, `Артефакты` и
   `Рекомендуемые навыки`; не добавляй пустые разделы.
4. Покажи полный черновик и временный путь, затем получи явное подтверждение перед
   записью.
5. После подтверждения создай только этот временный файл. Кратко сообщи, какие
   данные были обобщены или обезличены и какие ссылки оставлены вместо копирования.

## Результат

- Передача контекста пригодна для следующей сессии без скрытого состояния.
- Завершённое, текущее, следующее и блокеры разделены явно.
- Изменений Git и внешних систем нет.
