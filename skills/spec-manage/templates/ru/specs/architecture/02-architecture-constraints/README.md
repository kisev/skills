# 02 Архитектурные ограничения

## Назначение

Объясните, как внешне заданные ограничения `REQ-C-*` сужают пространство допустимых архитектурных решений.

## Включено

- Прямые ссылки на применимые владельцы `REQ-C-*` и вызванные каждым ограничением архитектурные последствия, компромиссы или запрещенные варианты.

## Исключено

- Второй нормативный список ограничений, внутренне выбранные проектные решения, предпочтения, риски и задачи реализации.

## Правила декомпозиции

Храните все последствия ограничений в этом `README.md`. Организуйте их по ID владеющего требования, а не по функции или компоненту, и не создавайте дочерние файлы.

## Ожидаемая структура

Для каждого применимого ограничения сопоставьте одну прямую ссылку `REQ-C-*` с его архитектурным эффектом. Кратко укажите, если внешние архитектурные ограничения отсутствуют.

## Шаблон содержания

Замените эти указания ссылками на ID ограничений и только их последствиями для целевой архитектуры, включая запрещенные альтернативы, где это существенно.
