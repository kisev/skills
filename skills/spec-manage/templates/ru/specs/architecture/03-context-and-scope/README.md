# 03 Контекст и границы

## Назначение

Определите границу системы и ее отношения с внешними людьми, системами и доменами доверия.

## Включено

- Внешние субъекты, пользователи, соседние системы, входящие и исходящие зависимости и передаваемая информация.
- Границы доверия и их пересечения на границе системы с прямыми ссылками на релевантные владельцы `REQ-*`.

## Исключено

- Внутренние компоненты, развернутая сетевая топология, размещение секретов, механизмы авторизации и дублирование протоколов интерфейсов.

## Правила декомпозиции

Храните полный контекст в этом `README.md`; не создавайте дочерние файлы. Используйте одну диаграмму System Context, только если она показывает границы яснее текста.

## Ожидаемая структура

Опишите обязанности внутри и вне scope, внешние субъекты и системы, взаимодействия, классы передаваемых данных и пересечения границ доверия.

## Шаблон содержания

Замените эти указания формулировкой границы системы; описаниями внешних субъектов и соседних систем; взаимодействиями через границу; границами доверия; прямыми ссылками на требования.
