# 06 Runtime-представление

## Назначение

Объясните, как строительные блоки целевого состояния взаимодействуют в архитектурно значимых runtime-сценариях.

## Включено

- Сквозные потоки управления и данных, переходы состояния, конкурентное или асинхронное поведение, сбои, тайм-ауты, повторы, восстановление и условия завершения.
- Прямые ссылки на требования к поведению и качеству, демонстрируемые каждым сценарием.

## Исключено

- Все обычные use case, статические описания компонентов, delivery-оркестрация, трассы реализации и тестовые скрипты.

## Правила декомпозиции

Этот `README.md` служит индексом и обзором сценариев. Добавляйте отдельный файл только для значимого сквозного сценария, требующего самостоятельного объяснения; не разделяйте по компонентам или шагам реализации.

## Ожидаемая структура

Для каждого сценария укажите триггер, участников, упорядоченные взаимодействия, изменения данных или состояния, пути сбоев и восстановления, терминальные условия и ссылки на требования. Используйте диаграмму sequence или state, только если она яснее текста.

## Шаблон содержания

Замените эти указания индексом сценариев целевого состояния с обычными и существенными аварийными путями, асинхронными границами, восстановлением и прямыми ссылками на обеспечиваемые `REQ-*`.
