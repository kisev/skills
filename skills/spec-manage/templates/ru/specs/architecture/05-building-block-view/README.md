# 05 Представление строительных блоков

## Назначение

Опишите статическую декомпозицию целевой системы на строительные блоки с самостоятельными обязанностями и границами зависимостей.

## Включено

- Системы, сервисы, компоненты, модули, слои или пакеты с самостоятельными обязанностями.
- Владение, предоставляемые и требуемые интерфейсы, направление зависимостей, локальность состояния и прямые ссылки на требования, обеспечиваемые каждым существенным блоком.

## Исключено

- Порядок runtime-взаимодействий, узлы развертывания, перечни исходных файлов, группировка по функциям и предполагаемые абстракции без самостоятельной обязанности.

## Правила декомпозиции

Этот `README.md` служит основным обзором и индексом. Добавляйте отдельный файл только для реальной подсистемы, сервиса, компонента, модуля, слоя или пакета, которому нужны самостоятельные подробности; не разделяйте по функциям или размеру документа.

## Ожидаемая структура

Начните с декомпозиции уровня системы, затем опишите обязанность, владельца, интерфейсы, зависимости и локальное состояние каждого блока. Используйте диаграммы Container или Component, только если они проясняют текст.

## Шаблон содержания

Замените эти указания иерархией строительных блоков; границами обязанностей и владения; предоставляемыми и требуемыми интерфейсами; правилами зависимостей; локальностью состояния; ссылками на требования и индексируемые файлы блоков.
