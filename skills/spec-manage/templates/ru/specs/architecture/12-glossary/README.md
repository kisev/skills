# 12 Глоссарий

## Назначение

Определите одно каноническое значение для неоднозначных терминов предметной области, продукта и архитектуры, используемых в спецификации.

## Включено

- Специфичные для проекта термины, перегруженные слова, сокращения и различия, толкование которых влияет на требования или архитектуру.

## Исключено

- Определения распространенных технологий, руководства, дублирование текста требований, имена реализации, не требующие пояснения, и неиспользуемая будущая терминология.

## Правила декомпозиции

Храните глоссарий в этом `README.md`; не создавайте дочерние файлы. Используйте одну запись на понятие и один предпочтительный термин на значение.

## Ожидаемая структура

Используйте алфавитный или другой стабильный список с термином, кратким каноническим определением, допустимыми синонимами и ссылками, где различие существенно.

## Шаблон содержания

Замените эти указания только терминами, необходимыми для устранения существенной неоднозначности в каноническом целевом состоянии.
