# Требования к качеству

## Назначение

Фиксируйте измеримые или проверяемые атрибуты качества системы.

## Включено

- Свойства производительности, надежности, безопасности, удобства использования и сопровождаемости.
- Условия, нагрузка, метрики, допустимые пороги и критерии проверки.

## Исключено

- Функциональное поведение, семантика интерфейсов, внешне заданные ограничения, общие пожелания без способа проверки, архитектурные механизмы и бэклог улучшений.

## Правила декомпозиции

В v1 храните все требования к качеству в этом `README.md`. Автоматическое разделение запрещено.
