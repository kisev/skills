# Требования к интерфейсам

## Назначение

Опишите внешние поверхности взаимодействия системы и их нормативную семантику.

## Включено

- Контракты публичных CLI, API, конфигурации и событий.
- Команды, поля, сообщения, порядок, валидация, ошибки протокола, версионирование и семантика совместимости на этих внешних поверхностях.
- Ссылки на формальные схемы и декларации.

## Исключено

- Поведение, не зависящее от транспорта и принадлежащее `REQ-F-*`, пороги качества, внутренние интерфейсы модулей, потенциальные будущие интерфейсы или полные копии деклараций OpenAPI, JSON Schema или CLI.

## Правила декомпозиции

Этот README служит обзором и индексом. Дополнительный файл разрешен только для реальной внешней поверхности: один интерфейс на файл, например `cli.md` или `http-api.md`.

## Ожидаемая структура

```text
interfaces/
├── README.md
└── [существующий-интерфейс].md
```

## Шаблон содержания

Перечислите реальные внешние поверхности и связанные `REQ-I-*`. В каждом дополнительном файле укажите источник истины, семантику протокола, ошибки, совместимость и инварианты; ссылайтесь на поведение, не зависящее от транспорта, вместо его повторения. Если внешних интерфейсов нет, объясните это вместо создания файлов.
