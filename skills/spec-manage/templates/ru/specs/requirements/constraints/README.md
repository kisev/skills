# Ограничения

## Назначение

Фиксируйте внешне заданные обязательные ограничения, сужающие допустимые решения.

## Включено

- Обязательные среда выполнения, платформа, инфраструктура, технология, закон, политика, стандарт и организационные границы, источник которых находится вне проектирования решения.

## Исключено

- Выбранная архитектура, внутренне выбранные технологии, предпочтения без нормативной силы, поведение, цели качества, архитектурные последствия, риски или технический долг.

## Правила декомпозиции

В v1 храните все ограничения в этом `README.md`. Автоматическое разделение запрещено.

## Ожидаемая структура

```text
constraints/
└── README.md
```

## Шаблон содержания

Используйте стабильный `REQ-C-NNN`, укажите внешнего владельца или основание каждого ограничения и проверку там, где она не очевидна. Раздел 02 архитектуры ссылается на эти ID и объясняет последствия без повторения ограничения.
