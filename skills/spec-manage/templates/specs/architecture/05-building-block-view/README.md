# 05 Building Block View

## Purpose

Describe the target system's static decomposition into responsibility-bearing building blocks and their dependency boundaries.

## Included

- Systems, services, components, modules, layers, or packages with independent responsibilities.
- Ownership, provided and required interfaces, dependency direction, state locality, and direct links to requirements provided by each material block.

## Excluded

- Runtime ordering, deployment nodes, source-file inventories, feature grouping, and speculative abstractions without an independent responsibility.

## Decomposition Rules

This `README.md` is the primary overview and index. Add one file only for a real subsystem, service, component, module, layer, or package that needs independent detail; never split by feature or document size.

## Expected Structure

Start with the system-level decomposition, then describe each block's responsibility, ownership, interfaces, dependencies, and local state. Use Container or Component diagrams only when they clarify the text.

## Content Template

Replace this guidance with the building-block hierarchy; responsibility and ownership boundaries; provided and required interfaces; dependency rules; state locality; requirement links; and links to any indexed block files.
