# Ограничения

## Назначение

Фиксируйте обязательные ограничения, сужающие допустимые решения.

## Включено

- Обязательные среда выполнения, платформа и инфраструктура; ограничения совместимости и политик; обязательные технологии и эксплуатационные границы.

## Исключено

- Предпочтения без нормативной силы, архитектурные последствия, риски или технический долг.

## Правила декомпозиции

В v1 храните все ограничения в этом `README.md`. Автоматическое разделение запрещено.

## Ожидаемая структура

```text
constraints/
└── README.md
```

## Шаблон содержания

Используйте стабильный `REQ-C-NNN`, основание для каждого ограничения и проверку там, где она не очевидна. Раздел архитектуры 02 ссылается на эти ID и объясняет их последствия.
