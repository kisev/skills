# Требования к интерфейсам

## Назначение

Опишите внешние поверхности взаимодействия системы и их нормативную семантику.

## Включено

- Контракты публичных CLI, API, конфигурации и событий.
- Гарантии совместимости, валидация, ошибки и ссылки на формальные схемы и декларации.

## Исключено

- Внутренние интерфейсы модулей, потенциальные будущие интерфейсы или полные копии деклараций OpenAPI, JSON Schema или CLI.

## Правила декомпозиции

Этот README служит обзором и индексом. Дополнительный файл разрешен только для реальной внешней поверхности: один интерфейс на файл, например `cli.md` или `http-api.md`.

## Ожидаемая структура

```text
interfaces/
├── README.md
└── [существующий-интерфейс].md
```

## Шаблон содержания

Перечислите интерфейсы и связанные `REQ-I-*`. В каждом дополнительном файле укажите его источник истины, семантику, ошибки, совместимость и инварианты. Если внешних интерфейсов нет, объясните это вместо создания файлов.
