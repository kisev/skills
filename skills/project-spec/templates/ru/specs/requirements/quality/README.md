# Требования к качеству

## Назначение

Фиксируйте измеримые или проверяемые атрибуты качества системы.

## Включено

- Цели производительности, надежности, безопасности и сопровождаемости.
- Условия, нагрузка, метрики, допустимые пороги и критерии проверки.

## Исключено

- Общие пожелания без способа их проверить, архитектурные механизмы и бэклог улучшений.

## Правила декомпозиции

В v1 храните все требования к качеству в этом `README.md`. Автоматическое разделение запрещено.

## Ожидаемая структура

```text
quality/
└── README.md
```

## Шаблон содержания

Используйте стабильный `REQ-Q-NNN` и указывайте контекст, метрику, цель и проверку. Используйте ISO/IEC 25010 только как контрольный список; не заявляйте соответствие.
