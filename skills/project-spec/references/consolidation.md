# Консолидация specification

Консолидация обязательна в каждом `spec-update`: canonical documents описывают
текущее состояние, а история живёт в Git. Проверь затронутую область на
дублирование норм, отменённые требования и временные планы, устаревшие ссылки и
заменённые ADR. Не удаляй подтверждённый non-scope, риск, границу совместимости или
необходимое объяснение только ради краткости.

До preview укажи либо `Consolidation: required` с областью и точными упрощениями,
либо `Consolidation: not required` с причиной. При недостатке evidence спроси
человека, а не удаляй текст по предположению.
