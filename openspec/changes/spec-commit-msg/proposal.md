# Proposal

## Why

commit-msg — core skill confirmed in the foundation renegotiation (see `renegotiate-foundation`): frequently used and staying. This change gives the component its exhaustive
specification and executes the renegotiation decisions that concern it.

One concise commit-message line from the staged or worktree diff; atomicity enforced (unrelated changes stop with a split proposal); language and format from repo configuration; Conventional Commits within 50 characters by default.

The only component with an existing OpenSpec capability spec; keep it current.
Open: exhaustive capability spec review.
