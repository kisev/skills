# @kisev/taskmatic

[English version](README.md)

Локальные задачи для человека и агентов: одно TypeScript/Node.js-приложение для
CLI, MCP, Markdown-экспорта и живой веб-доски только для чтения. Нужен Node.js 22.13+.

```shell
# Registry version
npm view --prefer-online @kisev/taskmatic@dev version

# Install
npm install --global @kisev/taskmatic@dev

# Installed package and active CLI
npm list --global @kisev/taskmatic --depth=0
taskmatic --version
```

Тег может сдвинуться между просмотром и установкой. Последние команды показывают
установленный пакет и CLI из PATH. Затем создайте и используйте доску:

```shell
taskmatic add "Check the first board"
taskmatic list
taskmatic mcp
taskmatic serve
```

Тег `dev` предоставляет сборку для разработки. Обновление переносимого скилла
`taskmatic` не обновляет приложение; для этого повторите npm-установку.
См. [настройку и миграцию](../../docs/ru/how-to/taskmatic.md).

## Совместимость

Сохранены SQLite-схема v1 файла `taskmatic.db`, каталог состояния, формат снапшота
и одиннадцать имён MCP-инструментов. Стандартный каталог:
`${XDG_STATE_HOME:-$HOME/.local/state}/agent-skills/taskmatic/`; `TASKMATIC_HOME`
или `--home` задают другой абсолютный нормализованный путь. Идентификаторы,
заметки, связи, события и действующие захваты сохраняются при переходе с Python.
Для машинного вывода используйте `--json`; `--clear-assignee` и `--clear-linked`
очищают необязательные поля.

`taskmatic-web serve` остаётся совместимым алиасом. Просмотру нужна существующая
база; сервер слушает только IPv4 loopback (по умолчанию `127.0.0.1:8765`), обновляет
снапшоты, позволяет переключать доски, фильтровать и читать заметки и историю.
Аутентификации для сетевого доступа нет; изменять карточки через браузер нельзя.
CLI и MCP изменяют данные в immediate-транзакциях; heartbeat продлевает захват без экспорта.

Markdown/HTML-зеркала производные и не служат источником изменений. Не коммитьте
базу и приватные экспорты. Перед сменой команд сохраните согласованную резервную
копию, а старую установку оставьте до завершения проверок. Npm-приложение не
редактирует пользовательскую MCP-конфигурацию и systemd-сервисы автоматически.
