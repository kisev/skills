# taskmatic-web

[English version](README.md)

`taskmatic-web` — «живая» веб-доска только для чтения для
[taskmatic](../../skills/taskmatic/): рендерит приватную SQLite-базу задач в
локальную канбан-страницу, которая обновляется, пока агенты и человек продолжают
работу.

## Установка

```bash
uv tool install git+https://github.com/kisev/skills#subdirectory=apps/taskmatic
```

или `pipx install` с той же целью. Приложение читает
`$TASKMATIC_HOME` или `${XDG_STATE_HOME:-$HOME/.local/state}/agent-skills/taskmatic/`
и никогда не пишет в базу.

## Использование

```bash
taskmatic-web serve            # http://127.0.0.1:8765
taskmatic-web serve --port 0   # занять свободный порт
taskmatic-web snapshot         # вывести живой JSON-снапшот
```

Страница умеет переключать доски, фильтровать по тексту и `#меткам`, показывать
детали карточки с заметками и активностью и периодически обновляться. Доска
строго read-only: любые изменения идут через CLI раннера скилла taskmatic или
MCP-инструменты.

## Границы

- Слушает только loopback-интерфейс; иных сетевых обращений нет.
- SQLite-соединение только на чтение; захваты и карточки меняются только
  инструментами taskmatic.
- Шаблон вьюера поддерживается побайтово идентичным статическому экспорту
  скилла контрактным тестом.
- Это пользовательское приложение, а не портативный раннер скилла: ему
  разрешены зависимости, хотя сейчас достаточно стандартной библиотеки
  Python 3.12+.
