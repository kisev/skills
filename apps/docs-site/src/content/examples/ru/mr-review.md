---
skill: mr-review
title: Ревью merge request на соответствие задаче
order: 10
prompt: |
  Проверь этот merge request: https://gitlab.example.com/group/project/-/merge_requests/7
steps:
  - title: Собирает точный контекст
    detail: |
      Читает merge request, diff, обсуждения, пайплайны и связанные issues
      только для чтения, привязанными к точным base, start и head ревизиям.
  - title: Подтверждает базовую задачу
    detail: |
      Задаёт один стартовый раунд: алиасы и effort OCR, цель и критерии
      приёмки из связанных issues и описания.
  - title: Запускает движок OCR
    detail: |
      Запускает один процесс OpenCodeReview на каждый выбранный алиас,
      параллельно, затем объединяет дубли и конфликты серьёзности с причинами.
  - title: Отвечает, решена ли задача
    detail: |
      Формирует вердикт в runbook с доказательствами, прогоны OCR, проверки
      и один блок черновиков, который начинается с проверки головы.
artifacts:
  - label: Runbook (фрагмент)
    language: markdown
    content: |
      ## Task fulfillment

      **Вердикт:** частично. Лимит действует на IP; критерий на пользователя
      не покрыт.

      ## OCR runs

      | Алиас | Провайдер | Модель | Effort | Режим | Код | Находки |
      | - | - | - | - | - | - | - |
      | fast | openai | gpt-5 | medium | параллельно | 0 | 2 |
      | deep | anthropic | claude-opus-5 | high | параллельно | 0 | 3 |

      ## Checks

      - Пайплайн: прошёл.
      - Упавшие задания: нет.
limitations: Только чтение. Создаёт только черновики GitLab; человек правит и публикует их в UI.

Ревьюер отвечает на один вопрос: решает ли изменение задачу, для которой оно
сделано? Находки приходят только из прогонов OCR, а публикует ревью человек.
