# shopmatic

[English version](README.md)

MCP stdio-сервер покупательского поиска по витринам маркетплейсов через CLI
`agent-browser`. Отвечает тремя инструментами — `shopmatic_search`,
`shopmatic_product`, `shopmatic_compare` — в единой JSON-схеме (название,
цена, URL, рейтинг), а каждый анонимный запрос выполняет в свежем
доказанно пустом профиле браузера.

## Почему браузер

Покупательские API маркетплейсов закрыты, готовые сторонние MCP-скрейперы
исключены решением. Поэтому shopmatic управляет настоящим браузером через
`agent-browser` (закреплён в корневом `mise.toml`), извлекает результаты
отрисованного SPA и возвращает структурированные данные. Прямые HTTP-запросы
к эндпоинтам сознательно не используются.

## Статус площадок

| Площадка | Статус | Основание |
| - | - | - |
| Wildberries | поддерживается | спайк-извлечение результатов поиска, 2026-10-05 |
| Яндекс Маркет | поддерживается | спайк-извлечение результатов поиска, 2026-10-05 |
| Ozon | заблокирован | антибот-челлендж не проходит из датацентровой сети; стоп-условие спайка запрещает обходы |

Заблокированная площадка остаётся зарегистрированной и отвечает явной
ошибкой вместо имитации поддержки.

## Анонимный и аккаунт-режим

Анонимный режим — поведение по умолчанию и обязателен для всех автоматических
вызовов: каждый прогон создаёт свежий каталог профиля под
`$XDG_CONFIG_HOME/shopmatic/profiles/anonymous/` (режим 0700), доказывает
отсутствие cookie до первой навигации и удаляет его после закрытия браузера.
Сессии маркетплейсов хоста никогда не используются.

Аккаунт-режим — только явный и ручной. Выполните
`shopmatic login <площадка>`, войдите руками в открывшемся окне браузера —
постоянный приватный профиль сохранит сессию для последующих прогонов
с `--account`. shopmatic сам никогда не вводит учётные данные и не выполняет
действий от имени аккаунта.

## Установка и запуск

Пакет собирается и запускается из репозитория через uv; `agent-browser` должен
быть на `PATH` (его предоставляет закреплённый Mise-инструмент):

```shell
uv run --locked shopmatic --version
uv run --locked shopmatic serve            # MCP stdio server
uv run --locked shopmatic search wildberries "клавиатура" --max-price 5000
uv run --locked shopmatic compare "клавиатура" --limit 5
uv run --locked shopmatic product wildberries 12345678
uv run --locked shopmatic login yandex-market
```

Подключение MCP-сервера из хоста:

```json
{"mcpServers": {"shopmatic": {"command": "uv", "args": [
  "--directory", "/path/to/apps/shopmatic", "run", "--locked", "shopmatic", "serve"]}}}
```

Вызовы инструментов возвращают единый JSON; заблокированные площадки и сбои
рендера возвращают явные ошибки инструмента. `SHOPMATIC_AGENT_BROWSER`
переопределяет исполняемый файл браузера, `SHOPMATIC_PROFILE_ROOT` — корень
профилей (используется тестами).

## Единая схема результата

```json
{
  "schema": "kisev-skills/shopmatic-result/v1",
  "marketplace": "wildberries",
  "kind": "search",
  "query": "клавиатура",
  "items": [
    {"position": 1, "id": "1474531458", "name": "…", "price": 119.0,
     "old_price": 255.0, "currency": "RUB", "rating": 4.8, "rating_votes": 8721,
     "url": "https://www.wildberries.ru/catalog/1474531458/detail.aspx"}
  ],
  "warnings": []
}
```

Рейтинги отсутствуют там, где витрина их не отрисовала (Wildberries рисует
их лениво); такие строки несут явные `null`, а конверт может содержать
warning. Ответы compare оборачивают конверты площадок под `comparisons`.

## Границы безопасности

Только read-only взаимодействие с витринами: поиск, карточки товаров, без
корзины, заказов и оформления. Учётные данные и cookie живут только в
приватном XDG-профиле, вне Git, логов и ответов инструментов. Селекторы
извлечения ломаются при редизайнах витрин; этот транспортный риск принят
решением, а неисправный адаптер отвечает явной ошибкой, а не догадкой.

## Разработка

```shell
uv run --locked pytest
uv run --locked mypy
uv run --locked ruff check .
```

Локальный `pyproject.toml` приложения повторяет выбор линтеров репозитория.
Тесты полностью офлайновые и работают со скриптованным фейковым
исполняемым файлом `agent-browser`; ни один тест не обращается к площадкам.
